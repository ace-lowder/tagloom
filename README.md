# Tagloom

Generate 13 Etsy-ready tags from a listing in under 60 seconds.
`Next.js | TypeScript | Vercel`

## About

Tagloom is an Etsy listing optimization tool for sellers with 20-500 listings who rely on organic search, solving slow and inconsistent tag creation with a one-click generator that turns listing title and description into usable tags; activation is when users copy tags into a live Etsy listing, pricing is free during MVP validation then planned at $9/month, and the next 30-day focus is shipping, collecting the first 25 feedback responses, and improving output relevance.

## Installation

1. Clone the repository.
2. Install dependencies.
   ```sh
   npm install
   ```
3. Run locally.
   ```sh
   npm run dev
   ```
